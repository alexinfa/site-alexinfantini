API REST Node.js

API REST per la gestione di un catalogo prodotti con autenticazione JWT.

📂 Repository

Descrizione

Backend REST sviluppato con Node.js ed Express per la gestione di un catalogo prodotti. Include autenticazione con JWT, validazione degli input e documentazione automatica con Swagger.

Tecnologie usate

  • Node.js + Express — server HTTP
  • MongoDB + Mongoose — database documentale
  • JWT — autenticazione stateless
  • Swagger UI — documentazione interattiva delle API

Endpoints principali

Metodo Endpoint Descrizione
GET /api/prodotti Lista prodotti
GET /api/prodotti/:id Dettaglio prodotto
POST /api/prodotti Crea prodotto
PUT /api/prodotti/:id Aggiorna prodotto
DELETE /api/prodotti/:id Elimina prodotto
