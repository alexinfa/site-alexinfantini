Dashboard Analytics

Dashboard interattiva per la visualizzazione di dati in tempo reale.

📂 Repository

Descrizione

Dashboard web per il monitoraggio di metriche aziendali in tempo reale. L’interfaccia mostra grafici aggiornati dinamicamente e permette di filtrare i dati per periodo.

Tecnologie usate

  • React — UI dichiarativa a componenti
  • TypeScript — sicurezza dei tipi end-to-end
  • Recharts — libreria di grafici basata su SVG
  • REST API — fonte dati con aggiornamento ogni 30 secondi

Funzionalità principali

  1. Grafici a linee, barre e torta configurabili
  2. Filtro per intervallo di date
  3. Esportazione dei dati in CSV
  4. Layout responsive per mobile e desktop
